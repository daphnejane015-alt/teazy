# Railway Deployment Guide

## Prerequisites
- Railway account (https://railway.app)
- GitHub repository with your code
- Telegram bot token from @BotFather

## Step 1: Push code to GitHub
```bash
git add .
git commit -m "Prepare for Railway deployment"
git push origin main
```

## Step 2: Create Railway Project
1. Go to https://railway.app and log in
2. Click "New Project" → "Deploy from GitHub repo"
3. Select your repository
4. Railway will auto-detect Laravel via `railway.toml`

## Step 3: Configure Environment Variables
In Railway dashboard, go to your project → Settings → Variables. Add these:

**Required:**
```
APP_ENV=production
APP_DEBUG=false
APP_KEY=<auto-generated by Railway>
APP_URL=<your-railway-domain>
```

**Database (Railway provides MySQL automatically):**
```
DB_CONNECTION=mysql
DB_HOST=<Railway provides this>
DB_PORT=3306
DB_DATABASE=<Railway provides this>
DB_USERNAME=<Railway provides this>
DB_PASSWORD=<Railway provides this>
```

**OpenWeatherMap:**
```
OPENWEATHER_API_KEY=your_openweather_api_key_here
```

**Telegram Bot:**
```
TELEGRAM_BOT_TOKEN=<your-bot-token-from-botfather>
TELEGRAM_BOT_USERNAME=TeazyTeaBot  # or your bot's username
TELEGRAM_WEBHOOK_URL=<leave blank - will use APP_URL>
```

## Step 4: Deploy
1. Click "Deploy" in Railway
2. Wait for build to complete (~2-3 minutes)
3. Railway will run migrations automatically (added to `railway.toml`)
4. Once deployed, Railway will provide a domain like `https://your-app.railway.app`

## Step 5: Set Telegram Webhook
After deployment, set the webhook to your Railway domain:

**Option A: Using Railway Console (Recommended)**
1. In Railway dashboard, open your project
2. Click "Console" tab
3. Run:
```bash
php artisan telegram:set-webhook
```

**Option B: Using HTTP Endpoint**
Visit this URL in your browser:
```
https://your-railway-domain/api/telegram/set-webhook
```

**Option C: Manual cURL**
```bash
curl "https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=https://your-railway-domain/api/telegram/webhook"
```

## Step 6: Verify
1. Test your bot in Telegram: send `/start` or `/recommend`
2. Check Railway logs if something fails
3. Verify webhook is set:
```bash
curl "https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getWebhookInfo"
```

## Important Notes
- Railway provides a MySQL database automatically - no need to create one
- The `APP_URL` will be set by Railway automatically
- Migrations run on every deploy via `php artisan migrate --force` in `railway.toml`
- The `TrustProxies` middleware is already configured (`protected $proxies = '*'`) so HTTPS works correctly
- Your Railway domain is persistent - it won't change between deployments

## Troubleshooting
- **Build fails**: Check Railway logs for dependency issues
- **Database connection error**: Verify Railway DB variables are set
- **Webhook not working**: Ensure `TELEGRAM_BOT_TOKEN` is correct and domain is HTTPS
- **502 errors**: Check if the app is running - Railway may need a restart
